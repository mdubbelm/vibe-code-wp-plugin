Plugin ideas

Not sure what to build? Pick an idea from this list and write your own prompt.

Use the prompt template from the preparation page to describe your chosen idea. Fill in the name, what it should do, where it should appear, and how it should behave — then paste it into your AI tool.

The four workshop ideas

Start here if you want a tried path. Try writing your own prompt first: the example prompts follow later in Round 1.

  • Reading Time Easy Shows "Estimated reading time: X minutes" above each blog post.
  • External Link Icon Easy Adds ↗ to links that point to other websites and opens them in a new tab.
  • Maintenance Mode Medium Shows an "under maintenance" page to visitors while you keep working. LocalWP only: it doesn't work reliably in Playground.
  • Custom Login Logo Medium Puts your own image on the WordPress login screen. It usually takes a second round with the AI before the image picker works.

Frontend — visible to visitors

  • Last Updated Date Easy Shows "Last updated on [date]" above or below a blog post.
  • Copyright Footer Easy Adds "© [year] [site name]" to the bottom of every page. The year updates automatically.
  • Author Bio Box Easy Shows a short author description with avatar below each post.
  • Simple Cookie Notice Easy Shows a "This site uses cookies" banner at the bottom of the page with a dismiss button. It informs visitors, it doesn't ask for consent: not enough if your site sets tracking cookies.
  • Custom 404 Message Easy Replaces the standard "Not Found" message with your own text and a link back to the homepage.
  • Reading Progress Bar Medium Shows a progress bar at the top of the page that fills as you scroll through a post.

Admin — visible in the WordPress dashboard

  • Admin Footer Text Easy Replaces "Thank you for creating with WordPress" at the bottom of every admin page with your own message.
  • Dashboard Welcome Widget Easy Adds a custom welcome message or quick-links panel to the WordPress dashboard.
  • Word Count Column Easy Adds a "Words" column to the posts overview so you can see the word count of each post at a glance.
  • Login Page Message Easy Adds a custom message below the login form — useful for multi-author sites ("Editors only — contact admin for access").
  • Missing Featured Image Warning Medium Shows a warning when you try to publish a post without a featured image set.

Site-wide — behind the scenes

  • Disable Emoji Easy Removes the WordPress emoji scripts from every page. Makes your site load slightly faster.
  • Remove Generator Tag Easy Removes the WordPress version number from your page source. A small privacy gain; it doesn't make an outdated site safer. Updating does.

Deeper (optional): AI inside WordPress

  • AI Title Ideas Hard An admin-only box on the post edit screen that asks the AI provider connected to your WordPress for three title suggestions. Needs WordPress 7.0 or newer, LocalWP and your own API key from an AI provider. The prompt is in the optional section of the prompts page.

Round 2: check and fix (20 minutes)

After the break, pick one track. Not sure? Take Check.

  • Check (default, for everyone whose plugin activates). Go to Tools → Plugin Check, choose your plugin, leave the Categories as they are (Plugin Repo ticked) and click Check it! Then pick one row whose Code contains Security, SettingSanitization, PreparedSQL or direct_file_access. Skip the rest, even Errors: readme, License and the like are paperwork for the WordPress.org directory. Use the explain prompt and then the fix prompt from the prompts page, re-install and run it again. Nothing to pick? The prompts page tells you what to do next.
  • Wider (your plugin didn't work, or you're done). Paste the same prompt into a second AI tool and compare the two results side by side, or pick a second idea from this page.
  • AI inside WordPress (optional). Only if you already have an API key from an AI provider and a LocalWP site on WordPress 7.0 or newer: build AI Title Ideas from the list above.
